## Описание проекта

«Кот-сапёр» — игра на Python и pygame по правилам классического
«Сапёра». Игрок открывает безопасные клетки, отмечает предполагаемые
мины флажками и начинает партию с тремя жизнями.

## Функциональные возможности

- Три уровня сложности.
- Безопасная область вокруг первого хода.
- Флажки и автоматическое открытие пустых клеток.
- Анимация попадания и отдельные экраны победы и поражения.

## Требования к системе

- Python 3.12
- pygame 2.6.1
- Windows, macOS или Linux с графическим рабочим столом

## Установка и запуск

Склонируйте репозиторий и откройте его папку в терминале.
Если репозиторий уже скачан, перейдите к созданию окружения.

```bash
git clone https://github.com/channhoo/PPP_3sem_3.3.git
cd PPP_3sem_3.3
```

### Windows (PowerShell)

```powershell
py -3.12 -m venv venv
.\venv\Scripts\python.exe -m pip install -r requirements.txt
.\venv\Scripts\python.exe main.py
```

### macOS и Linux

```bash
python3.12 -m venv venv
./venv/bin/python -m pip install -r requirements.txt
./venv/bin/python main.py
```

## Структура проекта

- `main.py` — окно игры, управление, отрисовка поля и анимация.
- `game.py` — расстановка мин, открытие клеток, жизни и проверка результата.
- `requirements.txt` — зависимость pygame.
- `assets/` — фон, портрет барса, мина-цветок и карточки победы и поражения.
- `test_game.py` — тесты игровой логики.

## Пример игры

Выберите уровень. Лёгкий — 9 × 9 и 10 мин, средний — 16 × 16 и 40 мин,
сложный — 16 × 30 и 99 мин. По умолчанию выбран средний.

1. Откройте клетку левой кнопкой мыши. На первом ходу выбранная клетка и её соседи безопасны.
2. Цифра показывает количество мин вокруг клетки, включая диагонали. Правой кнопкой можно поставить или снять флажок.
3. При открытии мины теряется одна из трёх жизней. Сработавшая мина остаётся на поле и продолжает учитываться в цифрах.
4. Откройте все безопасные клетки, чтобы победить. После потери всех жизней партия заканчивается. Скрытые мины становятся полупрозрачными.

Кнопка «Новая игра» или клавиша R начинает новую партию.
Клавиша Esc закрывает окно.
